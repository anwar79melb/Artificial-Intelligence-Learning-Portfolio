# Advanced Object-Oriented Programming with Python

## Overview

This section documents my study of advanced software development concepts using Python and Object-Oriented Programming (OOP).

The learning path begins with Python programming fundamentals and progressively introduces software design, object-oriented modelling, inheritance, polymorphism, data structures, design patterns, persistence, and concurrent programming.

Rather than focusing solely on Python syntax, the course emphasizes how software engineers analyze problems, model real-world systems, and develop maintainable, scalable, and reusable software solutions.

Throughout the course, theoretical concepts are reinforced through practical exercises, programming challenges, and project-based learning activities that reflect real-world software engineering practices.

---

## Learning Objectives

By completing this learning path, I developed my ability to:

- Apply object-oriented principles to software development problems.
- Design classes and object hierarchies that model real-world systems.
- Implement reusable, maintainable, and extensible software components.
- Apply inheritance, encapsulation, and polymorphism effectively.
- Select and implement appropriate data structures for different problem domains.
- Manage persistent application data using file handling and serialization.
- Apply fundamental software design patterns.
- Develop concurrent applications using threads and processes.
- Produce software solutions that follow professional software engineering principles.
