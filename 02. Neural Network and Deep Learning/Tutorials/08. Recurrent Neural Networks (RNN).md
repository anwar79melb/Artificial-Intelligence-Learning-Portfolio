# Tutorial 08: Recurrent Neural Networks (RNNs)

## Overview

So far, this course has focused primarily on feed-forward neural networks and Convolutional Neural Networks (CNNs), which are well suited for structured data and image classification tasks.

However, many real-world problems involve sequential data where the order of information matters. Traditional neural networks process inputs independently and have no memory of previous inputs. As a result, they struggle to model time-dependent relationships.

Recurrent Neural Networks (RNNs) were developed to address this limitation by introducing an internal memory mechanism that allows information to persist across time steps.

This tutorial introduces the foundations of Recurrent Neural Networks, sequence modelling, hidden states, Backpropagation Through Time (BPTT), common RNN architectures, and the challenges associated with training recurrent models.

# 1. Why Do We Need Recurrent Neural Networks?

Many real-world datasets contain information that changes over time.

Examples include:

- Stock prices
- Weather records
- Speech signals
- Sensor readings
- Text documents
- DNA sequences
- Medical signals

In these problems:

```text
Order Matters
```

The current value often depends on previous values.

---

## Traditional Neural Networks

A feed-forward network processes:

```text
Input
   ↓
Output
```

independently.

Each prediction is made without remembering previous inputs.

As a result:

```text
No Memory
```

exists between predictions.

---

## Recurrent Neural Networks

RNNs introduce:

```text
Memory
```

allowing information from previous time steps to influence future predictions.

# 4. Feed-Forward Networks and Time

Suppose we have observations:

```text
x₀

x₁

x₂

...
```

A traditional network processes each independently.

```text
x₀ → y₀

x₁ → y₁

x₂ → y₂
```

There is no connection between predictions.

---

## Limitation

The network cannot remember:

```text
Previous Inputs
```

making it ineffective for sequential learning.

---

# 5. Introducing Recurrence

The key innovation behind RNNs is:

```text
Recurrence
```

A recurrent neuron receives:

- Current input
- Previous internal state

and combines them.

---

## Mathematical Form

```math
y_t = f(x_t, h_{t-1})
```

Where:

- \(x_t\) = current input
- \(h_{t-1}\) = previous memory state
- \(y_t\) = output

---

# 6. Hidden States

The hidden state acts as the memory of the network.

At every time step:

```text
Current Input
      +
Previous Memory
      ↓
New Memory
```

---

## Purpose

The hidden state stores information about:

- Previous inputs
- Previous context
- Sequential dependencies

---

# 7. Recurrent Cells

A recurrent cell performs three operations:

### Input

Receives:

```text
Current Input xₜ
```

---

### Memory

Receives:

```text
Previous State hₜ₋₁
```

---

### Output

Produces:

```text
Current Output yₜ
```

and:

```text
Updated State hₜ
```

---

# 8. RNN State Update

A typical hidden state update is:

```math
h_t =
tanh(
W_{hh}h_{t-1}
+
W_{xh}x_t
)
```

Where:

- \(W_{hh}\) = recurrent weights
- \(W_{xh}\) = input weights

---

## Output Computation

```math
y_t
=
W_{hy}h_t
```

This allows information to flow through time.

---

# 9. Weight Sharing

One of the unique characteristics of RNNs is:

```text
Shared Parameters
```

The same weights are used at every time step.

---

## Benefits

✅ Fewer parameters

✅ Handles variable-length sequences

✅ Efficient learning

✅ Improved generalization

---

# 10. Unrolling an RNN

Although an RNN contains a loop internally, it can be visualized by expanding the network through time.

Example:

```text
x₀ → h₀ → y₀

x₁ → h₁ → y₁

x₂ → h₂ → y₂

x₃ → h₃ → y₃
```

This is called:

```text
Unrolling
```

the network.

# 17. Training RNNs

Training involves:

```text
Forward Pass
      ↓
Loss Computation
      ↓
Backward Pass

Weight Updates
```

However, RNNs require a special training method.

---

# 18. Backpropagation Through Time (BPTT)

Because RNNs are unrolled through time:

```text
Gradients must flow
through all time steps
```

This process is called:

```text
Backpropagation Through Time
(BPTT)
```

---

## Concept

Instead of backpropagating through layers:

```text
Layer 1 → Layer 2 → Layer 3
```

we backpropagate through:

```text
Time Step 1

Time Step 2

Time Step 3

...
```

---

# 19. Gradient Flow in RNNs

Every hidden state depends on previous hidden states.

Therefore:

```text
Gradients are repeatedly multiplied
through the sequence.
```

This creates optimization challenges.

---

# 20. Exploding Gradients

Exploding gradients occur when repeated multiplication causes gradients to become:

```text
Extremely Large
```

---

## Consequences

- Unstable training
- Oscillating updates
- Divergence

---

## Solution: Gradient Clipping

Limit gradient values before updating weights.

Example:

```python
clipnorm=1.0
```

Benefits:

✅ Stable training

✅ Prevention of numerical instability

---

# 21. Vanishing Gradients

Vanishing gradients occur when gradients become:

```text
Extremely Small
```

during backpropagation.

---

## Consequences

Earlier layers receive little learning signal.

Eventually:

```text
Learning Stops
```

for long-term dependencies.

---

# 22. Short-Term Memory Problem

Because gradients vanish:

RNNs tend to learn:

```text
Recent Information
```

while forgetting important events far back in the sequence.

---

## Example

Suppose the network must connect:

```text
Information at Step 1
```

with:

```text
Prediction at Step 100
```

Vanishing gradients make this extremely difficult.

---

# 23. Improving Gradient Flow

Several strategies can improve training.

---

## Better Activation Functions

Using:

```text
ReLU
```

can help preserve stronger gradients.

---

## Better Weight Initialization

Initialize recurrent weights carefully.

A common strategy is:

```text
Identity Matrix Initialization
```

---

## Architectural Improvements

The most successful solution is:

```text
Gated Recurrent Networks
```

which include:

- LSTM
- GRU

---

# 24. Weight Initialization

Instead of random initialization:

```math
I_n
```

(identity matrix)

may be used for recurrent weights.

---

## Benefits

✅ Better gradient flow

✅ Reduced vanishing effects

✅ More stable learning

---

# 25. Gated Recurrent Networks

Researchers developed more sophisticated recurrent cells.

Examples:

```text
LSTM

GRU

(Gated Recurrent Unit)
```

These networks can capture much longer dependencies.

---

## Why They Matter

They help solve:

```text

Vanishing Gradients

Long-Term Dependency Learning
```

### Dense Layer
