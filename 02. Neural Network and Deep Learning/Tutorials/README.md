## Repository Structure

The repository is organised as a collection of tutorial notes, exercises, and practical implementations that progressively introduce fundamental and advanced deep learning concepts.

Each tutorial is derived from the course lecture materials and expanded with additional explanations, examples, mathematical intuition, TensorFlow implementations, and practical exercises.
