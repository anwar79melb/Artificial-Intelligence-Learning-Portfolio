# Tutorial 05: Convolutional Neural Networks I (AlexNet and VGGNet)

## Overview

In previous tutorials, we explored Multilayer Perceptrons (MLPs), Backpropagation, Optimization, and Regularization. While MLPs perform well on structured data, they struggle when working directly with images because they ignore the spatial relationships between pixels.

Convolutional Neural Networks (CNNs) were developed to overcome this limitation. CNNs are specifically designed to process image data by automatically learning visual features such as edges, textures, shapes, and objects.

This tutorial introduces the foundations of computer vision, convolution operations, pooling layers, feature extraction, and two landmark CNN architectures:

- AlexNet
- VGGNet

These architectures transformed the field of computer vision and laid the foundation for modern deep learning image classification systems.

# 2. How Computers See Images

Humans perceive images as meaningful objects.

For example:

```text
A Cat

A Car

A Building
```

Computers see images differently.

An image is represented as a matrix of numbers.

---

## Grayscale Image

```text
[123, 54, 43]

[ 89,234,200]

[267, 53, 76]
```

Each number represents pixel intensity.

---

## RGB Image

Each pixel contains:

```text
Red Channel

Green Channel

Blue Channel
```

Example:

```text
(255,0,0)    → Red

(0,255,0)    → Green

(0,0,255)    → Blue
```

# 7. Convolution Layers

The convolution layer is the most important component of a CNN.

Its purpose is:

```text
Feature Extraction
```

Instead of connecting every neuron to every pixel:

```text
MLP Style
```

CNNs only view a small region of the image at a time.

This region is called the:

```text
Receptive Field
```

---

# 8. Local Connectivity

Unlike traditional neural networks:

```text
Every Neuron
        ↔
Every Input
```

CNN neurons only connect to nearby pixels.

Example:

```text
3 × 3 Patch

5 × 5 Patch

7 × 7 Patch
```

This greatly reduces the number of parameters.

---

# 9. Filters (Kernels)

CNNs use small matrices called:

```text
Filters

or

Kernels
```

to detect visual patterns.

Example:

```text
1  0  1
0  1  0
1  0  1
```

A filter slides across an image and searches for specific features.

Examples:

- Vertical edges
- Horizontal edges
- Diagonal lines
- Corners
- Textures

---

# 10. Convolution Operation

Convolution involves:

### Step 1

Select a small region of the image.

### Step 2

Place the filter over that region.

### Step 3

Multiply corresponding values.

### Step 4

Add the results.

### Step 5

Store the output value.

### Step 6

Move the filter.

### Step 7

Repeat.

---

## Result

The output becomes a:

```text
Feature Map
```

which highlights locations where the feature appears.

---

# 11. Feature Maps

A feature map represents where a particular visual feature exists within an image.

Examples:

```text
Edge Map

Texture Map

Corner Map

Pattern Map
```

Each filter produces one feature map.

---

# 13. CNN Output Volume

The output of a convolution layer is often represented as:

```text
Height × Width × Depth
```

Where:

- Height = feature map height
- Width = feature map width
- Depth = number of filters

Example:

```text
55 × 55 × 96
```

means:

```text
96 Feature Maps
```

each of size:

```text
55 × 55
```

---

# 14. Important CNN Parameters

## Filter Size

Examples:

```text
3×3

5×5

7×7
```

---

## Stride

The number of pixels the filter moves each step.

Example:

```text
Stride = 1

Stride = 2

Stride = 4
```

Larger strides produce smaller outputs.

---

## Receptive Field

The region of the input image visible to a neuron.

Larger receptive fields:

```text
Capture More Context
```

---

# 15. ReLU Activation

After convolution, CNNs typically use:

```text
ReLU
```

activation.

## Formula

```math
ReLU(z)=max(0,z)
```

---

## Purpose

- Introduces non-linearity
- Speeds up training
- Prevents saturation
- Improves feature learning

---

# 16. Pooling Layers

Pooling reduces the dimensionality of feature maps.

This makes CNNs:

- Faster
- More memory efficient
- More robust

---

## Max Pooling

Most common pooling method.

Example:

```text
1  3
6  4
```

Output:

```text
6
```

because:

```text
max(1,3,6,4)=6
```

---

## Average Pooling

Computes the mean value.

Example:

```text
1  3
5  7
```

Output:

```text
4
```

---

# 17. Why Pooling Is Important

Pooling:

✅ Reduces computation

✅ Reduces memory usage

✅ Preserves important information

✅ Improves translation invariance

---

# 26. VGGNet

VGGNet was developed by:

- Karen Simonyan
- Andrew Zisserman

from the Visual Geometry Group (VGG), Oxford University.

It achieved second place in the ImageNet 2014 competition.

---

# 27. VGG Philosophy

Instead of using large filters:

```text
11 × 11

7 × 7
```

VGG uses many:

```text
3 × 3
```

filters stacked together.

This allows:

- Greater depth
- More non-linearity
- Better feature learning

---

# 28. VGG16 Architecture

Characteristics:

### Convolution Layers

```text
3 × 3 Filters

Stride = 1

Padding = Same
```

### Pooling

```text
2 × 2 Max Pooling

Stride = 2
```

### Depth

```text
16 Layers
```

---

# 29. Advantages of VGG16

✅ Simple design

✅ Consistent architecture

✅ Powerful feature extraction

✅ Excellent transfer learning backbone

---

# 30. Limitations of VGG16

❌ Very large number of parameters

❌ High memory requirements

❌ Slow training

❌ Requires large datasets

---

# 31. Why Large Networks Need Large Data

When VGG16 was trained directly on MNIST:

```text
Poor Performance
```

because:

- The model was extremely large.
- MNIST is relatively small.
- The network could not learn efficiently from limited data.

This leads to the need for:

```text
Transfer Learning
```

---

# 32. Introduction to Transfer Learning

Instead of training VGG16 from scratch:

```text
Reuse Existing Weights
```

trained on ImageNet.

The pretrained network already knows how to detect:

- Edges
- Textures
- Shapes
- Objects

These learned features can be reused.

---

# 33. VGG16 in Keras

TensorFlow provides a pretrained VGG16 model.

Example:

```python
from tensorflow.keras.applications import VGG16

base_model = VGG16(
    weights="imagenet",
    include_top=False
)
```

The convolutional layers act as a:

```text
Feature Extractor
```

while new classification layers are added on top.
