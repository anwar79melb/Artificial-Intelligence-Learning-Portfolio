# Tutorial 09: Advanced Recurrent Neural Networks - LSTM and GRU

## Overview

In the previous tutorial, we introduced Recurrent Neural Networks (RNNs) and explored how they process sequential data using hidden states and memory.

Although RNNs are powerful sequence models, they struggle with long sequences because of the vanishing gradient problem. As information travels through many time steps, important information from earlier parts of the sequence is gradually forgotten. This limitation makes standard RNNs ineffective for learning long-term dependencies.

To address this challenge, more advanced recurrent architectures were developed:

- Long Short-Term Memory (LSTM)
- Gated Recurrent Unit (GRU)

These architectures introduce gating mechanisms that allow networks to selectively remember, update, and forget information, making them highly effective for language processing, time-series forecasting, speech recognition, and many other sequential learning problems.

# 1. Review: The Short-Term Memory Problem

Standard RNNs maintain memory using a hidden state.

At each time step:

```text
Current Input
      +
Previous Hidden State
      ↓
New Hidden State
```

This allows information to flow through time.

---

## The Problem

For very long sequences:

```text
Information from Earlier Time Steps
```

gradually disappears.

This occurs because gradients become increasingly small during Backpropagation Through Time (BPTT).

---

## Consequence

The network learns:

```text
Recent Information
```

more easily than:

```text
Distant Information
```

This is known as:

```text
Short-Term Memory
```

---

# 2. Why Standard RNNs Forget

Recall the hidden-state update:

```math
h_t
=
tanh
(
W_{hh}h_{t-1}
+
W_{xh}x_t
)
```

Every time step repeatedly applies:

- Matrix multiplication
- Non-linear activation functions

As the sequence grows:

```text
Gradients Shrink
```

leading to:

```text
Vanishing Gradients
```

---

# 3. Gated Recurrent Networks

To solve the memory problem, researchers introduced:

```text
Gated Recurrent Networks
```

These networks contain special control mechanisms called:

```text
Gates
```

which decide:

- What to remember
- What to forget
- What to update

---

## Major Architectures

### LSTM

```text
Long Short-Term Memory
```

---

### GRU

```text
Gated Recurrent Unit
```

Both architectures are designed to preserve important information across long sequences.

---

# 4. Review of Standard RNN Memory

A standard RNN processes information as:

```text
Previous Hidden State
      +
Current Input
      ↓
Concatenation
      ↓
tanh
      ↓
New Hidden State
```

The hidden state serves as the memory of the network.

However:

```text
Memory Is Easily Lost
```

when sequences become long.

---

# 5. Why Use the Tanh Function?

Standard RNNs commonly use:

```text
tanh
```

activation.

---

## Range

```text
-1 to 1
```

---

## Purpose

Tanh compresses values into a fixed interval.

Example:

```text
Input = 5
Output ≈ 0.99
```

```text
Input = -5
Output ≈ -0.99
```

---

## Benefits

✅ Stabilizes outputs

✅ Prevents exploding activations

✅ Helps training

---

# 6. The Limitation of Tanh

Although tanh stabilizes activations, repeated applications can reduce gradient magnitude.

Over many time steps:

```text
0.8 × 0.8 × 0.8 × ...
```

becomes very small.

Eventually:

```text
Gradient ≈ 0
```

and learning stops.

This motivates more sophisticated memory mechanisms.

---

# 7. What is LSTM?

Long Short-Term Memory (LSTM) is an improved recurrent architecture designed to:

```text
Preserve Important Information
Across Long Sequences
```

Unlike standard RNNs:

```text
LSTMs Learn What To Remember
And What To Forget
```

using specialized gates.

---

# 8. Core Components of LSTM

An LSTM contains:

### Cell State

```text
Long-Term Memory
```

---

### Hidden State

```text
Current Working Memory
```

---

### Gates

- Forget Gate
- Input Gate
- Output Gate

These components work together to manage information flow.

---

# 9. Cell State

The cell state is the most important innovation of LSTM.

Think of it as:

```text
Information Highway
```

running through the sequence.

---

## Purpose

Carry information from:

```text
Earlier Time Steps
```

to:

```text
Later Time Steps
```

with minimal modification.

---

## Benefit

Allows important information to survive much longer than in a standard RNN.

---

# 10. Understanding Gates

Gates control information flow inside the LSTM.

Each gate is implemented using neural network layers.

---

## What Gates Decide

### Keep Information

```text
Value ≈ 1
```

---

### Discard Information

```text
Value ≈ 0
```

---

### Partially Keep Information

```text
Value Between 0 and 1
```

---

# 11. The Sigmoid Function in Gates

LSTM gates use:

```text
Sigmoid Activation
```

---

## Range

```text
0 to 1
```

---

## Interpretation

```text
0 → Forget
```

```text
1 → Keep
```

This makes sigmoid ideal for controlling memory flow.

---

# 12. Forget Gate

The Forget Gate determines:

```text
What Information
Should Be Discarded
```

from the previous cell state.

---

## Inputs

The gate receives:

```text
Previous Hidden State

Current Input
```

---

## Output

A value between:

```text
0 and 1
```

for each memory component.

---

## Example

```text
0.95 → Keep Information

0.02 → Forget Information
```

---

# 13. Input Gate

The Input Gate determines:

```text
What New Information
Should Be Stored
```

in memory.

---

## Step 1

A sigmoid layer determines:

```text
Importance
```

of incoming information.

---

## Step 2

A tanh layer generates:

```text
Candidate Values
```

that may be added to memory.

---

## Step 3

These two results are multiplied.

The sigmoid output acts as a filter controlling the candidate information.

---

# 14. Updating the Cell State

After Forget and Input Gates are evaluated:

the cell state is updated.

---

## Formula

```math
C_t
=
f_t C_{t-1}
+
i_t \hat{C_t}
```

Where:

- \(f_t\) = Forget Gate output
- \(C_{t-1}\) = Previous Cell State
- \(i_t\) = Input Gate output
- \(\hat{C_t}\) = Candidate State

---

## Meaning

```text
Keep Important Old Information

+

Add Important New Information
```

---

# 15. Output Gate

The Output Gate determines:

```text
What Information
To Reveal
```

from the updated cell state.

---

## Process

### Step 1

Apply sigmoid:

```text
Determine Visibility
```

---

### Step 2

Apply tanh:

```text
Normalize Cell State
```

---

### Step 3

Multiply results.

This produces the next:

```text
Hidden State
```

---

# 16. Final LSTM Workflow

At each time step:

```text
Forget Gate
       ↓
Input Gate
       ↓
Update Cell State
       ↓
Output Gate
       ↓
New Hidden State
```

This allows the network to preserve important information across long sequences.

---

# 17. Why LSTMs Are Effective

LSTMs solve the long-term dependency problem by providing:

✅ Controlled memory updates

✅ Selective forgetting

✅ Long-term information preservation

✅ Improved gradient flow

✅ Better sequence modelling

---

# 18. What is a GRU?

A GRU (Gated Recurrent Unit) is a newer recurrent architecture.

It was developed as a simpler alternative to LSTMs.

---

## Key Difference

GRUs remove:

```text
Separate Cell State
```

and instead use only:

```text
Hidden State
```

for memory.

---

# 19. GRU Architecture

A GRU contains only:

### Update Gate

Controls memory updates.

---

### Reset Gate

Controls forgetting of previous information.

---

Compared with an LSTM:

```text
Fewer Gates

Fewer Parameters

Simpler Computation
```

---

# 20. Update Gate

The Update Gate combines the functionality of:

```text
Forget Gate
+
Input Gate
```

from LSTMs.

---

## Purpose

Determine:

```text
What To Keep

What To Update
```

from memory.

---

# 21. Reset Gate

The Reset Gate determines:

```text
How Much Past Information
Should Be Ignored
```

---

## Purpose

Allows the network to forget irrelevant history when necessary.

Example:

```text
Change Of Topic
```

in a sentence.

---

# 22. Advantages of GRUs

Compared with LSTMs:

✅ Simpler design

✅ Faster training

✅ Fewer parameters

✅ Lower memory usage

✅ Often similar performance

---

# 23. LSTM vs GRU

| Feature | LSTM | GRU |
|----------|----------|---------|
| Cell State | Yes | No |
| Hidden State | Yes | Yes |
| Forget Gate | Yes | No |
| Input Gate | Yes | No |
| Output Gate | Yes | No |
| Update Gate | No | Yes |
| Reset Gate | No | Yes |
| Parameters | More | Fewer |
| Training Speed | Slower | Faster |

---

# 24. When Should You Use LSTM?

LSTM is often preferred when:

- Long sequences are involved
- Complex dependencies exist
- Large datasets are available

Examples:

- Language modelling
- Speech recognition
- Machine translation

---

# 25. When Should You Use GRU?

GRUs are often preferred when:

- Faster training is important
- Computational resources are limited
- Dataset sizes are moderate

Examples:

- Real-time systems
- Time-series forecasting
- Lightweight NLP applications

```python
model = tf.keras.Sequential([
```
