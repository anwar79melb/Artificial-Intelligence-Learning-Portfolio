# Tutorial 10: Autoencoders and Variational Autoencoders (VAEs)

## Overview

In previous tutorials, we explored supervised deep learning models such as CNNs and RNNs that learn from labelled datasets. However, in many real-world scenarios, labelled data is expensive or difficult to obtain.

This tutorial introduces **Autoencoders** and **Variational Autoencoders (VAEs)**, two powerful unsupervised learning techniques capable of learning compact representations of data without requiring labels.

Autoencoders learn how to compress data into a low-dimensional representation known as a **latent space**, and then reconstruct the original data from this compressed representation. Variational Autoencoders extend this concept by introducing probability distributions into the latent space, enabling the generation of entirely new samples that resemble the training data.

These models form the foundation of modern generative AI applications, including image synthesis, representation learning, anomaly detection, and data compression.

# 5. What is an Autoencoder?

An Autoencoder is a neural network trained to:

```text
Reconstruct Its Input
```

---

## Architecture

An Autoencoder consists of:

```text
Input
   ↓
Encoder
   ↓
Latent Space
   ↓
Decoder
   ↓
Reconstruction
```

---

## Goal

Learn a compressed representation that preserves the most important information.

---

# 6. Autoencoders and Unsupervised Learning

Autoencoders belong to:

```text
Unsupervised Learning
```

because:

```text
No Labels Are Required
```

The network learns directly from the data itself.

---

## Training Pair

Input:

```text
x
```

Target:

```text
x
```

The model attempts to reproduce the original input.

# 7. The Encoder

The encoder performs:

```text
Data Compression
```

---

## Function

Map the input:

```text
x
```

to:

```text
z
```

where:

```text
z = Latent Representation
```

---

## Purpose

Remove unnecessary information while preserving important patterns.

---

# 8. The Latent Space

The latent space is the compressed representation learned by the encoder.

---

Example:

```text
Image
784 Features
```

↓

```text
Latent Vector
20 Features
```

---

## Why Compress?

Compression forces the model to learn:

```text
Important Structure
```

rather than memorizing data.

---

# 9. The Decoder

The decoder performs:

```text
Reconstruction
```

---

## Function

Map:

```text
Latent Space
```

back to:

```text
Original Data
```

---

## Objective

Generate:

```text

```

that is as similar as possible to:

```text
x
```

The reconstruction quality is measured using:

```text

```

---

## Common Loss Function

```math

||x-\hat{x}||^2
```

---

## Interpretation

Small Loss:

```text
Good Reconstruction
```

Large Loss:

```text
Poor Reconstruction
```

# 14. Limitations of Traditional Autoencoders

Although Autoencoders can reconstruct data effectively:

```text

```

is not structured.

---

## Problem

Sampling random latent vectors often produces:

```text

```

---

## Solution

Introduce probability distributions.

This leads to:

```text

```

# 15. What is a Variational Autoencoder?

A Variational Autoencoder (VAE) is an Autoencoder with a probabilistic latent space.

Instead of encoding a point:

```text
z
```

the encoder learns a distribution.

---

## Encoder Output

The encoder produces:

### Mean Vector

```text
μ
```

---

### Standard Deviation Vector

```text
σ
```

---

These describe a probability distribution in latent space.

---

Traditional Autoencoder:

```text
Input
   ↓

```

---

Variational Autoencoder:

```text
Input
   ↓
Probability Distribution
```

---

This allows:

```text

```

# 18. VAE Loss Function

The VAE objective consists of two parts.

---

## Reconstruction Loss

Measures reconstruction quality.

```math
||x-\hat{x}||^2
```

---

## Regularization Loss

Ensures the latent space follows a desired distribution.

This is achieved using:

```text
KL Divergence
```

---

# 19. KL Divergence

KL Divergence measures the distance between:

```text
Learned Distribution
```

and:

```text
Target Distribution
```

---

## Purpose

Force the latent space to resemble:

```text
Normal Distribution
```

---

Common Prior:

```math
N(0,1)
```

---

# 20. Why Use a Gaussian Prior?

Using:

```math
N(0,1)
```

encourages latent vectors to be:

✅ Smoothly distributed

✅ Well organized

✅ Easy to sample

✅ Resistant to memorization

---

## Benefit

Meaningful interpolation between samples becomes possible.

---

# 21. The Sampling Problem

During training:

```text
z ~ N(μ,σ²)
```

must be sampled.

---

## Challenge

Sampling is random.

Random operations block gradient flow.

Therefore:

```text
Backpropagation Fails
```

through the sampling operation.

---

# 22. The Reparameterization Trick

VAEs solve the sampling problem using:

```text
Reparameterization
```

---

Instead of directly sampling:

```math
z ~ N(\mu,\sigma^2)
```

we compute:

```math
z
=
\mu
+
\sigma \odot \epsilon
```

where:

```math
\epsilon
~
N(0,1)
```

---

## Benefit

The randomness is separated from the learnable parameters.

This enables:

```text
Backpropagation
```

through the entire network.
