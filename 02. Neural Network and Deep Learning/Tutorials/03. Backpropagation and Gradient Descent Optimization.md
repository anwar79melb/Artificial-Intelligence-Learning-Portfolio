# Tutorial 03: Backpropagation and Gradient Descent Optimization

## Overview

In the previous tutorial, we introduced Multilayer Perceptrons (MLPs), activation functions, loss functions, and image classification using TensorFlow.

However, an important question remains:

> How does a neural network actually learn?

The answer lies in two key concepts:

- Gradient Descent
- Backpropagation

Gradient Descent is the optimization algorithm used to minimize a network's loss function, while Backpropagation is the algorithm used to calculate the gradients required by Gradient Descent.

Together, these algorithms allow neural networks to continuously improve their predictions by adjusting their weights and biases during training.

# 1. Review: Loss Functions

Recall that the objective of neural network training is to minimize the prediction error.

Suppose a network predicts:

```text
Predicted = 0.1

Actual = 1.0
```

The prediction is incorrect.

The loss function measures how wrong this prediction is.

---

## Individual Loss

For one training example:

```math
L(f(x;W), y)
```

Where:

- \(x\) = input
- \(W\) = network weights
- \(y\) = actual output
- \(f(x;W)\) = predicted output

---

## Empirical Loss

Neural networks are trained using many examples.

Therefore we compute the average loss across the entire dataset.

```math
J(W)
=
\frac{1}{n}
\sum_{i=1}^{n}
L_i
```

This is called:

- Cost Function
- Objective Function
- Empirical Risk

The goal of training is:

```text
Find the weights W
that minimize J(W)
```

---

# 2. Binary Cross Entropy Loss

For binary classification problems:

```text
0 or 1
```

we commonly use Binary Cross Entropy.

Examples:

- Spam Detection
- Disease Detection
- Pass / Fail Classification

---

## Characteristics

Output:

```text
Probability between 0 and 1
```

Common Activation:

```text
Sigmoid
```

Goal:

```text
Minimize prediction error
while maximizing classification accuracy
```

# 3. Mean Squared Error (MSE)

For regression problems we use:

```text
Mean Squared Error (MSE)
```

Examples:

- House Price Prediction
- Temperature Prediction
- Sales Forecasting

---

## Formula

```math
MSE
=
\frac{1}{n}
\sum
(y-\hat y)^2
```

Where:

```text
y      = actual value

ŷ      = predicted value
```

---

# 4. Why Optimization Is Necessary

Training a neural network means finding the best possible weights.

Suppose a neural network contains thousands or even millions of weights.

The question becomes:

```text
Which combination of weights
produces the lowest loss?
```

This is an optimization problem.

Mathematically:

```math
W^*
=
argmin(J(W))
```

Where:

```text
W* = optimal weights
```

These are the weights that minimize the loss function.

---

# 5. Understanding the Loss Landscape

Imagine plotting the loss value for different weight combinations.

The result forms a landscape:

```text
High Loss
    ^
    |
    |
Valley
    |
    |
Low Loss
```

Neural network training is simply the process of navigating this landscape until the lowest point is reached.

---

## Goal

```text
Find the Lowest Point
```

which corresponds to:

```text
Minimum Loss
```

---

# 6. What Is a Gradient?

A gradient tells us:

```text
Which direction causes loss
to increase most rapidly.
```

It is essentially:

```text
The slope of the loss function.
```

Mathematically:

```math
\frac{\partial J(W)}
     {\partial W}
```

---

## Intuition

Imagine standing on a hill.

The gradient tells you:

```text
Which direction is uphill.
```

Since we want lower loss:

```text
We move downhill.
```

Therefore:

```text
Negative Gradient
```

points toward lower loss.

---

# 7. Gradient Descent

Gradient Descent is the most common optimization algorithm in machine learning.

Its purpose is simple:

```text
Minimize the Loss Function
```

by repeatedly updating the weights.

---

# 8. Gradient Descent Algorithm

## Step 1

Initialize weights randomly.

```math
W \sim N(0,\sigma^2)
```

---

## Step 2

Calculate network predictions.

---

## Step 3

Calculate loss.

---

## Step 4

Compute gradients.

```math
\frac{\partial J(W)}
     {\partial W}
```

---

## Step 5

Update weights.

```math
W
\leftarrow
W
-
\eta
\frac{\partial J(W)}
     {\partial W}
```

where:

```text
η = Learning Rate
```

---

## Step 6

Repeat until convergence.

---

# 9. Weight Update Equation

The most important equation in neural network training is:

```math
W
\leftarrow
W
-
\eta
\nabla J(W)
```

Where:

```text
W  = Current Weight

η  = Learning Rate

∇J = Gradient
```

This equation is applied repeatedly during training.

---

# 10. What Is Backpropagation?

Gradient Descent requires gradients.

Backpropagation is the algorithm used to compute those gradients efficiently.

---

## Purpose

Determine:

```text
How much each weight
contributed to the final error.
```

Once we know that:

```text
Weights can be updated.
```

---

# 11. Two Training Phases

Neural network training consists of:

---

## Phase 1: Forward Pass

Input data flows forward through the network.

```text
Input
   ↓
Hidden Layers
   ↓
Output
```

The network produces:

- Predictions
- Loss

---

## Phase 2: Backward Pass

The error is propagated backwards.

```text
Loss
  ↓
Output Layer
  ↓
Hidden Layers
  ↓
Input Layer
```

Gradients are calculated for every weight.

This process is called:

```text
Backpropagation
```

---

# 12. The Chain Rule

Backpropagation relies on one of the most important concepts in calculus:

```text
Chain Rule
```

Suppose:

```math
y = f(u)
```

and

```math
u = g(x)
```

Then:

```math
\frac{dy}{dx}
=
\frac{dy}{du}
\times
\frac{du}{dx}
```

---

## Why This Matters

Neural networks contain many interconnected calculations.

Example:

```text
Weight
   ↓
Hidden Neuron
   ↓
Output
   ↓
Loss
```

The Chain Rule allows us to calculate the effect of any weight on the final loss.

---

# 13. Gradient of the Output Weight

Suppose:

```text
Input
  ↓
Hidden Neuron
  ↓
Output Neuron
  ↓
Loss
```

To compute:

```math
\frac{\partial J}
     {\partial w_2}
```

we apply:

```math
\frac{\partial J}
     {\partial y}
\times
\frac{\partial y}
     {\partial w_2}
```

This tells us:

```text
How much changing w₂
affects the loss.
```

---

# 14. Gradient of Earlier Weights

For earlier weights:

```math
\frac{\partial J}
     {\partial w_1}
```

the Chain Rule expands further:

```math
\frac{\partial J}
     {\partial y}
\times
\frac{\partial y}
     {\partial z}
\times
\frac{\partial z}
     {\partial w_1}
```

This recursive application is the essence of Backpropagation.

---

# 15. Why Backpropagation Is Powerful

Without Backpropagation:

```text
Computing gradients
would be extremely expensive.
```

With Backpropagation:

```text
Gradients are computed efficiently
for every weight in the network.
```

This allows modern deep learning models to train effectively.

---

# 16. Learning Rate

The learning rate controls:

```text
How large each weight update is.
```

Represented by:

```math
η
```

---

## Small Learning Rate

Example:

```text
η = 0.00001
```

Advantages:

- Stable training

Disadvantages:

- Very slow convergence

---

## Large Learning Rate

Example:

```text
η = 1.0
```

Advantages:

- Larger updates

Disadvantages:

- Risk of overshooting
- Training instability
- Divergence

---

## Good Learning Rate

A suitable learning rate balances:

```text
Speed
and
Stability
```

---

# 17. Problems in Gradient Descent

Real-world optimization is not always simple.

Loss landscapes can contain:

```text
Valleys

Plateaus

Ridges

Local Minima
```

These make optimization challenging.

---

## Local Minimum

Gradient descent may become trapped in a low region that is not the best solution.

```text
Local Minimum
    ≠
Global Minimum
```

---

## Plateaus

Flat regions where gradients become very small.

Training may slow significantly.

---

# 18. Learning Rate Scheduling

Instead of using a fixed learning rate, modern neural networks often adjust it during training.

---

## Why?

Early Training:

```text
Large Steps
```

Later Training:

```text
Small Precise Steps
```

---

# 19. Power Scheduling

Learning rate decreases gradually.

Example:

```text
0.1
↓
0.05
↓
0.025
↓
...
```

Benefits:

- Smooth convergence
- Less oscillation

---

# 20. Exponential Scheduling

The learning rate decays exponentially.

Example:

```math
η_t
=
η_0
(0.1)^{t/s}
```

Useful for:

```text
Long Training Runs
```

---

# 21. Piecewise Scheduling

Maintain a constant learning rate for a period.

Example:

```text
Epoch 1-5     → 0.1

Epoch 6-10    → 0.01

Epoch 11-15   → 0.001
```

Commonly used in image classification tasks.

---

# 22. Performance Scheduling

A more intelligent approach.

Reduce the learning rate only when:

```text
Validation Loss Stops Improving
```

TensorFlow provides:

```python
ReduceLROnPlateau
```

which automatically performs this task.

---

# 23. Optimization Algorithms

Gradient Descent has many improved variants.

---

## SGD

Stochastic Gradient Descent

Benefits:

- Simple
- Fast
- Widely used

---

## RMSProp

Benefits:

- Adaptive learning rate
- Handles noisy gradients

---

## Adam

Combines:

- Momentum
- Adaptive Learning Rates

Benefits:

- Fast convergence
- Excellent default choice

Most commonly used optimizer today.

---

## Adagrad

Adapts the learning rate based on parameter history.

Works well for sparse data.

---

## Adadelta

Improved version of Adagrad.

Avoids aggressive learning rate decay.

---

# 24. Implementing Optimization in TensorFlow

TensorFlow makes optimization very simple.

Example:

```python
optimizer = tf.keras.optimizers.Adam()
```

Other options:

```python
tf.keras.optimizers.SGD()

tf.keras.optimizers.RMSprop()

tf.keras.optimizers.Adagrad()

tf.keras.optimizers.Adadelta()
```

The optimizer automatically applies gradients during training.

---

# 25. Automatic Differentiation

Modern deep learning frameworks automatically compute gradients.

TensorFlow provides:

```python
tf.GradientTape()
```

which:

1. Records computations.
2. Computes gradients automatically.
3. Updates weights.

This removes the need to manually calculate derivatives.
