# 1. Review: Gradient Descent

Recall the Gradient Descent update equation:

```math
W
\leftarrow
W
-
\eta
\frac{\partial J(W)}
     {\partial W}
```

Where:

- \(W\) = weights
- \(\eta\) = learning rate
- \(J(W)\) = loss function

The problem is that calculating gradients over an entire dataset can become computationally expensive for large datasets.

---

# 2. Batch Gradient Descent

Batch Gradient Descent computes gradients using:

```text
The Entire Dataset
```

before updating the weights.

---

## Algorithm

### Step 1

Initialize weights randomly.

### Step 2

Compute loss using every training sample.

### Step 3

Compute gradients.

### Step 4

Update weights.

### Step 5

Repeat until convergence.

---

## Advantages

✅ Stable updates

✅ Accurate gradient estimates

✅ Predictable convergence

---

## Disadvantages

❌ Computationally expensive

❌ Slow with large datasets

❌ Requires significant memory

---

# 3. Stochastic Gradient Descent (SGD)

Stochastic Gradient Descent updates weights using:

```text
One Training Example
```

at a time.

---

## Algorithm

### Step 1

Initialize weights randomly.

### Step 2

Select a single training sample.

### Step 3

Compute gradient.

### Step 4

Update weights immediately.

### Step 5

Repeat.

---

## Advantages

✅ Fast updates

✅ Works well for large datasets

✅ Lower memory requirements

---

## Disadvantages

❌ Noisy updates

❌ Less stable convergence

❌ May oscillate around the minimum

---

# 4. Mini-Batch Gradient Descent

Mini-Batch Gradient Descent combines the strengths of Batch and Stochastic Gradient Descent.

Instead of using:

```text
1 Sample
```

or

```text
Entire Dataset
```

it uses:

```text
Small Batch of Samples
```

typically:

```text
32
64
128
256
```

examples at a time.

---

## Algorithm

### Step 1

Initialize weights.

### Step 2

Select a batch of size B.

### Step 3

Compute gradients.

### Step 4

Update weights.

### Step 5

Repeat.

---

## Advantages

✅ Faster than Batch GD

✅ More stable than SGD

✅ Efficient GPU utilization

✅ Most common approach in deep learning

---

# 5. Batch Normalization

Deep neural networks often suffer from unstable activations during training.

This can slow learning and make training difficult.

Batch Normalization addresses this problem.

---

## Purpose

Batch Normalization:

```text
Normalizes Layer Inputs
```

during training.

---

## Process

For each mini-batch:

### Step 1

Compute mean.

```math
\mu_B
```

### Step 2

Compute variance.

```math
\sigma_B^2
```

### Step 3

Normalize inputs.

### Step 4

Scale using:

```math
\gamma
```

### Step 5

Shift using:

```math
\beta
```

---

## Benefits

✅ Faster convergence

✅ More stable training

✅ Allows higher learning rates

✅ Helps reduce vanishing gradients

✅ Can improve generalization

---

# 6. Batch Normalization Parameters

Each Batch Normalization layer introduces:

```text
γ (Scale)

β (Shift)

μ (Mean)

σ (Standard Deviation)
```

---

## Trainable Parameters

```text
γ

β
```

These are learned during training.

---

## Non-Trainable Parameters

```text
μ

σ
```

These are running estimates maintained during training.

# 7. Underfitting and Overfitting

One of the biggest challenges in machine learning is achieving good generalization.

---

## Underfitting

Occurs when the model is too simple.

Characteristics:

```text
High Training Error

High Testing Error
```

The model fails to learn important patterns.

---

## Good Fit

Characteristics:

```text
Low Training Error

Low Validation Error
```

The model generalizes well.

---

## Overfitting

Occurs when the model becomes too specialized to the training data.

Characteristics:

```text
Low Training Error

High Validation Error
```

The model memorizes training examples rather than learning general patterns.

---

# 8. What Is Regularization?

Regularization refers to techniques used to reduce overfitting.

Goal:

```text
Improve Generalization
```

rather than simply maximizing training accuracy.

---

## Common Techniques

- L1 Regularization
- L2 Regularization
- Dropout
- Early Stopping
- Max-Norm Regularization

---

# 9. L1 Regularization

L1 regularization adds a penalty based on the magnitude of weights.

---

## Effect

Encourages many weights to become:

```text
0
```

creating sparse models.

---

## Advantages

✅ Feature selection

✅ Simpler models

✅ Interpretability

---

## Typical Use Cases

```text
Sparse Feature Problems

High-Dimensional Data
```

---

# 10. L2 Regularization

L2 regularization adds a penalty proportional to the squared weights.

---

## Effect

Discourages large weights.

Keeps weight values small without necessarily removing them.

---

## Advantages

✅ Better generalization

✅ Smoother models

✅ Very popular in deep learning

---

## Example in TensorFlow

```python
kernel_regularizer=
tf.keras.regularizers.l2(0.01)
```

---

# 11. Combined L1 and L2 Regularization

TensorFlow also supports:

```python
tf.keras.regularizers.l1_l2()
```

which combines both approaches.

Benefits:

- Sparsity from L1
- Stability from L2

---

# 12. Dropout

Dropout is one of the most widely used regularization techniques.

---

## How It Works

During training:

```text
Randomly Disable Neurons
```

Example:

```text
50% Dropout
```

means roughly half of the neurons are temporarily ignored during a training pass.

---

## Why It Works

Without Dropout:

```text
Neurons may become overly dependent
upon specific neighboring neurons.
```

With Dropout:

```text
Each neuron must learn
more robust features.
```

---

## Benefits

✅ Reduces overfitting

✅ Encourages feature diversity

✅ Improves generalization

---

## Example

```python
tf.keras.layers.Dropout(0.2)
```

This drops:

```text
20% of neurons
```

during training.

---

# 13. Early Stopping

Sometimes neural networks continue learning even after reaching their best validation performance.

This eventually leads to:

```text
Overfitting
```

---

## Solution

Stop training early.

---

## Concept

Monitor:

```text
Validation Loss
```

Training ends when:

```text
Validation Loss
Stops Improving
```

for several epochs.

---

## Benefits

✅ Prevents overfitting

✅ Saves training time

✅ Produces better models

---

# 14. Model Checkpointing

TensorFlow provides:

```text
ModelCheckpoint
```

callback.

---

## Purpose

Save the best model during training.

Example:

```text
Epoch 10 → Best Performance
Epoch 50 → Worse Performance
```

The best model from epoch 10 can be restored.

---

## Advantages

✅ Prevents losing the best weights

✅ Works well with Early Stopping

---

# 15. EarlyStopping Callback

TensorFlow provides:

```text
EarlyStopping
```

callback.

---

## Functionality

Monitor:

```text
Validation Loss
```

If no improvement occurs for several epochs:

```text
Training Stops
```

---

## Patience Parameter

Example:

```python
patience=5
```

Meaning:

```text
Wait 5 epochs
before stopping.
```

---

# 16. Combining EarlyStopping and Checkpoints

A common workflow:

```text
Train Model
      ↓
Monitor Validation Loss
      ↓
Save Best Model
      ↓
Stop When Improvement Stops
      ↓
Restore Best Model
```

This approach is widely used in professional deep learning projects.

---

# 17. Max-Norm Regularization

Max-Norm Regularization constrains weight values.

---

## Idea

Prevent weights from becoming excessively large.

---

## Benefits

✅ More stable training

✅ Reduced overfitting

✅ Works well with Dropout

---

## TensorFlow Example

```python
kernel_constraint=
tf.keras.constraints.max_norm(3.0)
```

This limits the magnitude of each neuron's weight vector.

---

# 18. Comparing Regularization Techniques

| Technique | Purpose |
|------------|------------|
| L1 | Sparse models |
| L2 | Prevent large weights |
| Dropout | Randomly disable neurons |
| Early Stopping | Stop before overfitting |
| Model Checkpoint | Save best model |
| Max-Norm | Limit weight magnitude |
| Batch Normalization | Stabilize activations |

---

# 19. Recommended Modern Training Pipeline

A typical neural network today often includes:

```text
Input Layer
      ↓
Dense Layer
      ↓
Batch Normalization
      ↓
ReLU
      ↓
Dropout
      ↓
Dense Layer
      ↓
Batch Normalization
      ↓
ReLU
      ↓
Output Layer
```

Training usually includes:

```text
Adam Optimizer

Mini-Batch Training

Early Stopping

Model Checkpoints
```

---

# Practical Example

A TensorFlow model may use:

```python
model = tf.keras.Sequential([
    tf.keras.layers.Dense(
        300,
        activation="relu"
    ),

    tf.keras.layers.BatchNormalization(),

    tf.keras.layers.Dropout(0.2),

    tf.keras.layers.Dense(
        100,
        activation="relu"
    ),

    tf.keras.layers.Dense(10)
])
```
