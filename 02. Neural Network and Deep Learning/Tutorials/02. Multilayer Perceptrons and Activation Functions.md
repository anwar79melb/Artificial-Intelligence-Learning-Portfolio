# 1. Review of the Perceptron

A perceptron receives a set of inputs, multiplies each input by a weight, sums the results, adds a bias, and passes the result through an activation function.

## Mathematical Form

For a perceptron with \(n\) inputs:

```math
y = g
\left(
w_0 + \sum_{i=1}^{n} x_i w_i
\right)
```

Where:

- \(x_i\) = input values
- \(w_i\) = weights
- \(w_0\) = bias
- \(g\) = activation function
- \(y\) = output

---

## Matrix Representation

The weighted sum can be written as:

```math
y = g(w_0 + X^T W)
```

Where:

```text
X = Input Vector

W = Weight Vector
```

This compact representation becomes extremely useful when neural networks grow larger.

# 2. Activation Functions

An activation function determines whether a neuron should activate and what signal it should pass forward.

Without activation functions, neural networks behave like simple linear models regardless of how many layers they contain.

---

## Why Are Activation Functions Important?

Activation functions:

- Introduce non-linearity into neural networks.
- Help learn complex decision boundaries.
- Determine how information flows between neurons.
- Prevent outputs from growing uncontrollably.
- Enable deep networks to learn sophisticated patterns.

---

## Linear vs Non-Linear Models

### Linear Model

```text
Input
  ↓
Linear Transformation
  ↓
Output
```

Can only learn simple relationships.

---

### Non-Linear Model

```text
Input
  ↓
Activation Function
  ↓
Output
```

Can learn much more complex relationships.

---

# 3. Common Activation Functions

## Sigmoid (Logistic Function)

The sigmoid activation squashes any value into the range:

```text
0 to 1
```

### Formula

```math
σ(z)=\frac{1}{1+e^{-z}}
```

### Output Range

```text
0 ≤ σ(z) ≤ 1
```

### Characteristics

Advantages:

- Easy to interpret as probability.
- Useful for binary classification.

Disadvantages:

- Can suffer from vanishing gradients.
- Less common in modern hidden layers.

### Common Usage

```text
Binary Classification
```

Examples:

- Spam detection
- Disease prediction
- Pass/fail classification

---

# 4. Hyperbolic Tangent (Tanh)

Tanh is similar to sigmoid but outputs values between:

```text
-1 and 1
```

### Formula

```math
tanh(z)=
\frac{e^z-e^{-z}}
     {e^z+e^{-z}}
```

### Output Range

```text
-1 ≤ tanh(z) ≤ 1
```

### Advantages

- Zero-centered output.
- Faster convergence than sigmoid.
- Useful in recurrent networks.

### Common Usage

```text
Hidden Layers
Recurrent Neural Networks (RNNs)
```

---

# 5. Rectified Linear Unit (ReLU)

ReLU is the most widely used activation function in modern deep learning.

### Formula

```math
ReLU(z)=max(0,z)
```

### Output

```text
If z < 0 → 0

If z > 0 → z
```

### Advantages

- Fast computation.
- Reduces vanishing gradient issues.
- Works extremely well for deep networks.
- Dominates computer vision tasks.

### Common Usage

```text
CNNs

Deep Neural Networks

Computer Vision Models
```

---

# 6. Softmax

Softmax converts outputs into a probability distribution.

Unlike sigmoid, Softmax handles multiple classes.

### Example

Suppose a model predicts:

```text
Cat     : 0.10

Dog     : 0.75

Horse   : 0.15
```

Softmax guarantees:

```text
All outputs sum to 1
```

making interpretation straightforward.

### Common Usage

```text
Multi-Class Classification
```

Examples:

- Digit recognition
- Object classification
- Fashion MNIST

---

# 7. Exponential Linear Unit (ELU)

ELU is an improved activation function designed to keep activations closer to zero.

### Benefits

- Allows negative outputs.
- Improves learning dynamics.
- Helps gradients flow through deep networks.
- Can converge faster than ReLU.

### Common Usage

```text
Deep Neural Networks
```

where improved convergence is desired.

---

# 8. What is a Multilayer Perceptron?

A Multilayer Perceptron (MLP) extends a single perceptron by introducing one or more hidden layers.

---

## Motivation

Single-layer perceptrons can only solve:

```text
Linearly Separable Problems
```

Examples:

✅ AND

✅ OR

❌ XOR

To solve non-linear problems, additional layers are required.

---

# 9. Architecture of an MLP

A simple MLP contains:

```text
Input Layer
      ↓
Hidden Layer(s)
      ↓
Output Layer
```

Example:

```text
Input Layer
      ↓
Hidden Layer (3 Neurons)
      ↓
Output Layer
```

Every neuron in one layer is connected to every neuron in the next layer.

This is called a:

```text
Fully Connected Network

(Dense Network)
```

---

# 10. Hidden Layers

Hidden layers enable neural networks to learn intermediate features from data.

Example:

### Image Classification

```text
Input Image
       ↓

Edges
       ↓

Shapes
       ↓

Objects
       ↓

Prediction
```

Each hidden layer extracts increasingly useful information.

# 12. Loss Functions

How does a neural network know it made a mistake?

The answer is:

```text
Loss Functions
```

Loss measures how wrong a prediction is.

---

## Example

Actual:

```text
1
```

Predicted:

```text
0.1
```

The prediction is poor.

The loss will be high.

---

### Goal of Training

```text
Minimize Loss
```

A smaller loss means a better model.

---

# 13. Empirical Loss

Individual losses are combined across the dataset.

This is often called:

```text
Cost Function

Objective Function

Empirical Risk
```

Average loss:

```math
J(W)
=
\frac{1}{n}
\sum_{i=1}^{n}
L_i
```

where:

```text
Lᵢ = loss of each sample
```

---

# 14. Binary Cross Entropy Loss

Used for:

```text
Binary Classification
```

Examples:

```text
Pass / Fail

Spam / Not Spam

Cancer / No Cancer
```

Binary Cross Entropy rewards accurate probability predictions.

---

## Characteristics

Expected Output:

```text
0 or 1
```

Common Activation:

```text
Sigmoid
```

---

# 15. Mean Squared Error (MSE)

Used for:

```text
Regression Problems
```

Examples:

```text
House Price Prediction

Temperature Forecasting

Stock Price Prediction
```

Formula:

```math
MSE
=
\frac{1}{n}
\sum
(y-\hat y)^2
```

Where:

```text
y      = actual value

ŷ      = predicted value
```
