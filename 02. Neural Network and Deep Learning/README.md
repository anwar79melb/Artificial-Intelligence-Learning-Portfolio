# Neural Networks and Deep Learning with TensorFlow and Keras

## Overview

This repository documents my study of **Neural Networks and Deep Learning** using Python, TensorFlow, and Keras.

The course explores the theoretical foundations and practical implementation of modern deep learning systems, beginning with artificial neurons and perceptrons before progressing through multilayer neural networks, optimization techniques, convolutional neural networks, transfer learning, recurrent neural networks, and generative artificial intelligence models.

Rather than focusing solely on mathematical theory, the learning materials emphasize the development of practical deep learning solutions through hands-on experimentation, model construction, training, evaluation, and deployment using industry-standard frameworks.

Throughout the course, concepts are reinforced through practical exercises, TensorFlow implementations, laboratory activities, and real-world applications spanning computer vision, sequence modelling, natural language processing, and generative AI.

---

## Learning Objectives

By completing this learning pathway, I developed the ability to:

- Understand the biological and mathematical foundations of neural networks.
- Design and implement artificial neural networks using TensorFlow and Keras.
- Apply activation functions, loss functions, and optimization algorithms effectively.
- Train deep neural networks using backpropagation and gradient-based learning.
- Implement Multilayer Perceptrons (MLPs) for classification and regression tasks.
- Improve model performance through normalization and regularization techniques.
- Develop Convolutional Neural Networks (CNNs) for computer vision applications.
- Apply transfer learning using state-of-the-art pretrained models.
- Design Recurrent Neural Networks (RNNs) for sequential and time-series data.
- Implement Long Short-Term Memory (LSTM) and Gated Recurrent Unit (GRU) architectures.
- Explore unsupervised representation learning using Autoencoders and Variational Autoencoders (VAEs).
- Develop generative models using Generative Adversarial Networks (GANs).
- Build practical deep learning solutions for real-world Artificial Intelligence problems.
